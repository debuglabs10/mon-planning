# 🌟 Mon planning

Un planning interactif pour les enfants, avec une partie **Matin ☀️** et une partie **Soir 🌙**.

L'enfant coche chaque étape terminée et est récompensé :

- ✨ une petite animation et un son à chaque étape cochée
- 🏆 une grande fenêtre « Bravo champion ! » avec des confettis et une mélodie quand il termine le matin
- 🏆 la même chose quand il termine le soir
- 📅 le planning se remet à zéro automatiquement chaque jour

## Utilisation

Ouvre simplement l'adresse du site (GitHub Pages) sur un téléphone, une tablette ou un ordinateur.

Les cases cochées sont gardées en mémoire dans le navigateur pour la journée.

## Modifier les étapes

Ouvre le fichier `index.html` et cherche la ligne :

```
Pour modifier le planning
```

Chaque étape est écrite sous la forme `["icône","texte"]`. Tu peux changer le texte ou l'icône, en ajouter ou en supprimer.

## Mettre le site en ligne

1. Dans le dépôt GitHub, ouvre **Settings** puis **Pages**.
2. Sous **Branch**, choisis `main` puis clique sur **Save**.
3. Après une minute ou deux, l'adresse du site apparaît en haut de la page.

## Fichiers

- `index.html` : le planning (tout est dans ce seul fichier)
- `README.md` : cette présentation
